# Decisions

Settled choices, recorded so contributors (human or agent) do not re-open them. To change one, add a new entry that supersedes it; do not edit history. When a task forces a choice the specs do not cover, make the smallest reasonable choice and append it here in the same PR.

| ID | Decision | Rationale |
|---|---|---|
| D1 | **Backend: Go** with `github.com/gopacket/gopacket` (maintained fork). Live capture via `gopacket/pcap` (cgo + libpcap); file replay via `gopacket/pcapgo` (pure Go). | Throughput, single static-ish binary, memory safety. Replay and tests need no libpcap. |
| D2 | **Frontend: TypeScript (strict) + three.js + Vite**, tested with Vitest (units) and Playwright (end-to-end). Exact versions pinned in `web/package.json`. | three.js is a WebGL renderer that covers every visual in DESIGN.md; TypeScript makes the protocol types checkable. |
| D3 | **One binary.** `vite build` output in `web/dist` is embedded with `//go:embed all:dist` in `web/embed.go` (package `web`). `web/dist/.gitkeep` is committed so `go build`/`go test` work before the frontend is built. | One download, one origin, simple security model. |
| D4 | **Single Go module at the repo root**: `module github.com/PurpleSentinel/cyber-city`. Layout in AGENTS.md. The prototype dirs `sniffer/`, `frontend/`, `tools/generator/` are removed in T0.2. | Conventional layout; lets `internal/` packages be shared by the binary and tools. |
| D5 | **Auth = loopback bind + one-time token exchanged for a session cookie + strict Origin check.** The printed URL is `http://127.0.0.1:8080/auth?token=<T>`; `/auth` sets `cc_session` (HttpOnly, SameSite=Strict, Path=/) and redirects to `/`. `/ws` and `/api/*` require the cookie and an allowed `Origin`. | Browsers cannot set headers on WebSockets; a cookie keeps the token out of WebSocket URLs, logs and history. |
| D6 | **Time comes from packets, not the wall clock.** Aggregation windows, RTT, idle timeouts and detectors use packet timestamps. Live capture behaves the same because packet timestamps are close to now. | Deterministic replay and golden tests. |
| D7 | **The server classifies; the frontend renders.** Categories, districts, device class, services and events are computed in Go. The frontend never parses IP addresses or ports for meaning. | One source of truth; makes `--anonymize` safe; keeps TS simple. |
| D8 | **Metadata only.** Snap length 256 bytes (headers only). Byte counts use the on-wire length (`CaptureInfo.Length`), not the captured length. No payload is parsed, stored or sent. | Privacy; the prototype's `len(packet.Data())` would under-count once snaplen is reduced. |
| D9 | **MAC vendor table from the IEEE MA-L registry CSV** (`https://standards-oui.ieee.org/oui/oui.csv`), converted by `go generate` into `internal/enrich/oui_table.go` (committed). Not Wireshark's `manuf` (GPL). | Public registry, licence-clean. |
| D10 | **GeoIP is optional and offline**: `--geoip` takes a user-supplied GeoLite2-City `.mmdb`, read with `github.com/oschwald/maxminddb-golang`; `geo.home` must be set too. Tests use a tiny `.mmdb` generated by fixturegen with `github.com/maxmind/mmdbwriter`. Nothing is bundled and nothing is fetched. | GeoLite2's licence forbids redistribution; no network calls. |
| D11 | **IoT buildings are magenta, not red.** The concept used red for IoT and also for risky traffic; red is reserved for risk (cleartext/legacy traffic, scan and flood effects). | Avoid one colour meaning two things. |
| D12 | **The mock traffic generator is retired**; demos use `--read testdata/pcap/demo.pcap --loop`. | A replayed pcap exercises the real pipeline and cannot drift from the schema. |
| D13 | **MAC and vendor only for local hosts that are not behind a router.** A MAC address seen as the L2 peer for ≥ 5 distinct external IPs is a gateway: the gateway host gets that MAC, and external hosts get none. | Every external IP arrives with the router's MAC; attributing it would mislabel the whole Outlands. |
| D14 | **Heuristic detectors only**, labelled "Heuristic — not an IDS" in the UI and README. | Credibility; avoid implying security guarantees. |
| D15 | **Supported platform: Linux** (amd64, arm64) for live capture. macOS may work but is not tested in CI. Replay mode works anywhere Go runs. | Keep CI and privilege handling tractable. |
| D16 | **Deterministic output ordering.** Every array in protocol messages is sorted (rules in PROTOCOL.md). Go map iteration order must never reach the wire. | Golden tests. |
| D17 | **The city is solid, lit and shadowed; never wireframe.** Buildings, plots and ground use `MeshStandardMaterial` with a hemisphere light, a shadow-casting directional "moon", a procedural RoomEnvironment and ACES tone mapping. The neon look comes from emissive windows, edges and rim plus bloom on a solid body. Enforced by ESLint, Vitest and the e2e shading test (VISUAL_SPEC, TESTING). | The prototype's wireframe boxes read as a debug view; shaded volumes give depth, scale and a believable skyline. |
| D18 | **Toolchain pins:** Go ≥ 1.25 (required by `gopacket/gopacket` v1.7), TypeScript 6.0.x (the newest `typescript-eslint` 8.72 supports `<6.1`; TypeScript 7 waits for lint support), Vite 8, Vitest 5, ESLint 10, three.js 0.186. `web/package.json` pins exact versions; Dependabot proposes bumps. | Reproducible builds; avoid an unsupported linter/compiler pair. |
| D19 | **`web/node_modules` is excluded from Go by a generated `go.mod`** (npm `postinstall`). Some npm packages ship `.go` files (e.g. `flatted`) that `go ./...` would otherwise build. | Keeps `go vet ./...` and `go test ./...` clean without listing packages by hand. |
| D20 | **YAML via `go.yaml.in/yaml/v3`**, the maintained continuation of the archived `gopkg.in/yaml.v3`. Config and districts files are decoded with unknown keys rejected. `--listen` requires an explicit host, so `:8080` (all interfaces) can no longer be configured by accident. | Supported library; typos in config fail loudly. |
| D21 | **Multicast and broadcast addresses are not hosts.** Flows to a group address (e.g. mDNS `224.0.0.251`, SSDP `239.255.255.250`) are still reported with that address as `dst`, but no Host is created for it; the frontend credits such flows to the sender only. | A group is not a machine; drawing it as a building would mislead. |
